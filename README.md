🛒 POS Inventory System

A modern Point of Sale (POS) Inventory Management System built using the MERN stack (MongoDB, Express, React, Node.js). This project helps businesses manage products, cart operations, and sales efficiently with a clean and responsive user interface.

🚀 Features
📦 Product management (Add, View, Update, Delete)
🛒 Real-time cart system
💰 Automatic total calculation
📊 Inventory tracking
🔄 Redux state management
🌐 REST API integration
📱 Responsive UI for all devices
⚡ Fast and optimized performance

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/babjanshaik-png/pos.git
cd pos-inventory-system
2️⃣ Setup Backend
cd backend
npm install
npm start
3️⃣ Setup Frontend
cd frontend
npm install
npm start
🌐 Environment Variables

Create a .env file in backend:

MONGO_URI=your_mongodb_connection_string
PORT=5000
