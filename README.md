## 📌 Overview

A **modern Point of Sale (POS) Inventory Management System** built using the **MERN Stack (MongoDB, Express, React, Node.js)**.

It helps businesses efficiently manage:
- Products
- Cart system
- Billing
- Inventory tracking

---

## 🚀 Features

- 📦 Product CRUD operations  
- 🛒 Real-time cart system  
- 💰 Automatic billing calculation  
- 📊 Inventory management  
- 🔄 Redux Toolkit state management  
- 🌐 REST API integration  
- 📱 Fully responsive UI  
- ⚡ Optimized performance
